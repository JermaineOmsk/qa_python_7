1. В файле data хранится информация об адресах (url), ручках(Endpoints), некорректных данных курьера (InvalidDataCourier), данные о заказчике(User) и данне ответа сервера(Response)
2. В файле functions хранятся две функции:
    1)Создание курьера со случайными данными
    2)Удаление курьера по id
3. В файле conftest хранятся две фикустуры:
    1)Проверка, что логин совбоден и можно зарегистрировать курьера, с последующим удалением курьера
    2)Регистрация нового курьера и последующее удаление после теста      
4. В папке test хранятся тесты для отдельных ручек
